O que o programa faz: identifica a classe do IP, a máscara padrão, o endereço de rede e o broadcast.
Que é um projeto individual de faculdade, de 2010, feito em VB.NET
Como executar: Abrir no visual estudio e rodar 
Limitações: usa só a máscara padrão da classe, sem CIDR nem sub-redes
